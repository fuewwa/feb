feb

fast & easy build

Write your build steps once in a file called febconf. Run any of them with one short command. feb is a small alternative to GNU Make with no dependencies, written in Rust.

Install feb Read the syntax

Syntax

A febconf has two kinds of entries: params and targets.

name = value
Defines a param. Names may contain letters, digits, _ and -.
true false
A bool, always in lowercase.
42 1.5
An int and a double.
"text" 'text'
A string. It must be in double or single quotes, so a string is never mistaken for a bool or a number. It cannot contain its own quote character.
${name}
Inserts a param into a command.
// text
A comment. Quoted text is left alone, so "http://example.com" is safe.
name { … }
Defines a target: a list of commands, one per line.
TAB
Every command line starts with one real TAB character. Spaces are rejected, and the error names the line.

Commands run in order through sh -c, or cmd /C on Windows. The first command that fails stops the build.

Usage

feb reads the febconf in the current folder.

$ feb run
$ feb cppver clear

Run one target, or several in the order you list them. Every name is checked before anything starts.

$ feb

Run the first target in the file.

$ feb --list

Print the names of all targets.

Install

feb is built with cargo. Install the Rust toolchain for your system first.

Arch Linux

sudo pacman -S --needed base-devel git rust

Debian and Ubuntu

sudo apt update
sudo apt install -y build-essential curl git
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
. "$HOME/.cargo/env"

macOS

xcode-select --install
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
. "$HOME/.cargo/env"

Windows

Install the Visual Studio Build Tools with the “Desktop development with C++” workload, then run this in PowerShell and restart the terminal.

winget install Rustlang.Rustup
rustup default stable

Then build feb

$ git clone https://github.com/fuewwa/feb
$ cd feb
$ cargo install --path .
$ feb --help

The binary goes to ~/.cargo/bin. If your shell says the command is not found, add that folder to your PATH.
